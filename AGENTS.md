# AGENTS.md

## Stack
Bun 1.2.19 + Turbo 2.10 monorepo. Workspaces `apps/*`, `packages/*` with catalog deps (`package.json:4`). Runtime is Bun — use `bun` not `npm`/`pnpm`. Better-T-Stack scaffold (`bts.jsonc`). No CI workflows.

## Layout
- `packages/agent/src/` — research engine: `planner.ts` → `researcher.ts` (Exa) → `critic.ts` → `synthesizer.ts`, wired by `orchestrator.ts`. Types/schemas in `types.ts`, config defaults in `config.ts`.
- `apps/server/src/` — Express on Bun (`index.ts` port 3000, `research.ts` SSE `POST /api/research`, `cli.ts` headless runner). Built with `tsdown`.
- `apps/web/src/` — Next.js 16 on port 3001, streams `AgentEvent` SSE. Preserves auto-generated `apps/web/AGENTS.md` — do not delete (regenerated by `next dev`).
- `packages/env/` — `server.ts` (`@t3-oss/env-core`) and `web.ts` (`@t3-oss/env-nextjs`). `packages/config/tsconfig.base.json` — strict, `verbatimModuleSyntax`, `noUnusedLocals/Params`, `moduleResolution: bundler`. `packages/ui/` — shared shadcn.

## Setup
```bash
bun install
cp apps/server/.env.example apps/server/.env  # fill AWS_BEDROCK_API_KEY, EXA_API_KEY, CORS_ORIGIN=http://localhost:3001
```
`NEXT_PUBLIC_SERVER_URL` needed for web. `SKIP_ENV_VALIDATION=1` bypasses `packages/env/src/server.ts:27` validation. `.env`, `traces/`, `docs/` are gitignored.

## Agent Architecture (non-obvious)
- **Orchestrator owns recursion** (`packages/agent/src/orchestrator.ts:70`): planner → parallel researchers (semaphore capped by `config.parallelism`, default 5) → critic per result → if `verdict: recurse` and `depth < maxDepth`, spawn one deeper subquestion (`id: "${id}-r"`) → synthesizer. Every decision emits `AgentEvent` (`types.ts:89`) consumed by both CLI (`ConsoleLogger`) and SSE.
- **Budget is hard-enforced in code** (`BudgetTracker:36`): `maxTotalSearches` (default 10) is the global Exa cap; on exhaustion emits single `budget_hit` and synthesizes with what exists. `maxDepth` default 2.
- **Degradation, not crash**: single `researchSubquestion` failure emits `subquestion_failed` and continues (`orchestrator.ts:136`); synthesizer failure emits `synthesis_fallback` and returns deterministic `fallbackReport` (`orchestrator.ts:243`).
- **Structured hand-offs** are zod schemas (`types.ts`) — never pass raw strings between roles.
- **Structured output**: All roles use JSON-instruct (prompt demands JSON) + zod parse + retry. Do not switch to `generateObject`/`response_format: json_object`.
- **LLM config** (`config.ts:8`): AWS Bedrock (us-east-1) only. Models: `bedrockPlannerModel: us.anthropic.claude-sonnet-4-6`, `bedrockResearcherModel: zai.glm-4.7`, `bedrockCriticModel: zai.glm-5`, `bedrockSynthesizerModel: us.anthropic.claude-sonnet-4-6`. Timeouts: `llmTimeoutMs` 60s, `searchTimeoutMs` 30s, retries with exponential backoff (`maxRetries` 2).

## Conventions & Gotchas
- `exports: {".": "./src/index.ts"}` (`packages/agent/package.json:6`) — agent is consumed as source, no build step needed for dev.
- Server `build` is `tsdown`, output `dist/index.mjs`; `start` runs that file, `dev` runs `bun run --hot src/index.ts` directly.
- Web connects to `NEXT_PUBLIC_SERVER_URL`; CORS origin must match `apps/server/.env` `CORS_ORIGIN`.
- Tests in `orchestrator.test.ts` cover recurse path, budget cap, single-failure degradation, synthesis fallback — use as reference for wiring a fake `Llm` via `generateJson` prompt matching.
